## Delivered behavior required

Animation uses the injected Clock, the existing capped cadence and cached current-turn facts. A live agent indication must not freeze solely because a long-running tool emits no fresh signal, while signal ages and diagnosed stalls remain honest. Status blinking applies only to agent-processed active turns; disabled animation and monochrome/static presentation keep readable state words. Slow I/O must not serialize unrelated frame updates or create overlapping refreshes that outlive their widget.

Recent has a fixed heading and a bounded, independently scrollable body with a visible scrollbar or directional cues. Task selection remains one stable task identity across active and Recent sections; search, filters, full History, mouse/keyboard navigation and inline detail retain their contracts. Task rows have no extra blank cells between states or terminal records. Recent state words are `Done` and `Cancelled` in secondary grey; their icons may retain useful state meaning.

Popup screens have no root gutter that moves the transparent underlay. Insets belong to their popup frame/container. Use the approved HTML's graphite/surface/steel palette, centered maximum width and coherent cell-quantized outer/inner spacing; verify actual frame coordinates rather than equating DOM presence with visibility. `Esc ×` stays visible at the popup header's right edge, outside scrollable body content, and closes by mouse or Escape. At the 20×8 reachability floor, adapt frame spacing to keep critical controls reachable. Preserve native Select Escape precedence, entered drafts, selection, reading position and originating task/role context.

Resources retain the exact Host/Shikiru/Agents labels, single-space dot separators, sampled host-total RAM denominator, disjoint attribution, cache identity and unknown/stale/failed meanings. Project Diagnostics composes the existing resource, engine, open-fault and Docker facts, with configured external/built-in widgets still reachable. No independent sampler, provider inference or new monitoring timer is introduced.

The advertised Home Enter answer/resolve route works from normal Home focus without duplicate inspection or premature command submission. Native input/forms retain Enter. Remove duplicated task-ID prefixes only in display; stable escalation IDs, packet content, structured proposals and durable engine recovery actions remain available.

Shikiru-owned task window and pane labels use a contrasting graphite background. Shipped agent pane titles contain words instead of role/state glyphs. Preserve task window templates, project terminal title, `0:dashboard`, focus retention and explicit custom configuration. Keep the existing wall clock: the operator questioned its proposed removal, which was an interpretation rather than a requested change. Never mutate global tmux styles or other sessions.

Integration still attempts semantic resolution through existing Implementer conflicts and Leader consult/verify turns with the established round limit. Actual unmerged paths and other continuation errors are distinct. Preserve conflicted worktrees, useful bounded Git failure evidence and truthful retries; do not loop on an inappropriate stale completed report, discard changes, increase retry budgets or guess a semantic resolution. Agent proposals are shown only when recorded. A non-content Git failure explains its recovery action instead of pretending it is an unresolved content choice.

The latest durable command appears to the right of footer actions at usable wide widths and wraps coherently at compact widths. It identifies action/target, Pending delivery timing, Applied effect or Rejected cause; it is not a promise that a queued message was consumed. Full command history remains reachable when text truncates or the tiny footer is hidden.
