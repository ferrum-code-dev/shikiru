Keyboard: Tab reaches fields and buttons; Enter/Space activates buttons. In-terminal comboboxes open with ArrowDown or Enter/Space; while open, Up/Down and Home/End move, Enter/Space choose, and Escape closes. Menus choose above or below their trigger within the popup body using browser geometry; this is a CSS-pixel approximation, not terminal-cell positioning. Tab closes and advances. Assessment selects outside the terminal keep native browser behavior. Rung lists handle Up/Down only while a rung button has focus. There are no page-wide shortcuts.
